#
Welcome to my Software Quality Assurance portfolio. This repository contains end-to-end manual testing documentation for the **Interactive College Scheduling System** web application.

## About the Project
This application is a web-based master data management system (Courses, Lecturers, Rooms) and academic scheduler featuring business logic validation (1 Credit/SKS = 50 minutes, operational hours 07:00 - 16:00 WIB), as well as schedule conflict detection for classes and rooms.

## Testing Scope
* **Functional Testing**
* **Positive & Negative Testing**
* **Business Logic Validation** (Operational Hours & Conflict Detection)
* **UI/UX Basic Inspection**
